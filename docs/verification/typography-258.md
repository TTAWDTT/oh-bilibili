# 关注、动态与每周必看的中文排版验收

三页使用同一位长昵称作者「云上的实验室」、同一部中英混排标题作品和同一段长推荐语。样本提供有封面、缺封面两个版本。「关注」进入作者空间的按钮、动态作者名和周刊署名都应打开同一位 UP 主，点击作品则进入观看页。

## macOS 检查记录

同版 Mac 客户端已在普通窗口打开关注、动态和每周必看。打开第 400 期目录中的《EUV光刻机 | "上帝的手术刀"》并返回后，键盘焦点回到该作品的观看按钮。

2026-11-24 在 macOS 26.6.2 的 Chrome 158 上运行本版开发预览，展开侧栏，视口分别为 1440×900 和 1100×900 CSS 像素。浏览器原始 DPR 为 1。彩色及灰度各留了一份截图。

三页标题距离各自滚动容器左缘均为 32 px。页标题使用 26/34 px，普通作者和作品名使用 15/22 px，正文使用 15/24 px，辅助信息使用 12.5/18 px。斜线两侧分别为字号和行高。周刊的主题及主推作品另有更大的字号。缺图前后的封面位置和大小一致。

字体引擎报告三个标题实际使用随包的 LXGWWenKai-Regular。屏蔽字体文件后本机用了已安装的 LXGWWenKai-Medium。再从字体栈排除本机文楷，实测标题由 PingFangSC-Semibold 排印。

## Windows 125% 复查

1. 系统显示设置选 125%，应用保留普通窗口和展开的侧栏。用同一版本依次检查上表三条路径，留意长名字、灰度下的选中状态，以及从周刊较靠下的位置看完视频再返回。
2. 要对齐同一份样本，在仓库根目录执行 `npm ci`、`npm run web`。打开终端显示的本机预览地址，在地址后加 `?typographySample=with-cover&loggedIn`。将 `with-cover` 改成 `missing` 可查看同一份缺图样本。
3. 若要自动记录宽度、真实字体、焦点和截图，在另一个 PowerShell 窗口执行下列命令。脚本读取 Edge 启动时的原始 DPR。桌面应用的系统缩放和 WebView2 呈现仍须实屏确认。

```powershell
$env:TYPOGRAPHY_HEADED = "1"
$env:TYPOGRAPHY_EXPECT_DPR = "1.25"
$env:TYPOGRAPHY_OUTPUT = "$env:TEMP\oh-bilibili-258"
node scripts/watch-smoke.mjs --typography-only
```
